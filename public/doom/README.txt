DOOM (1993) shareware — portfolio easter egg
============================================

Game
----
DOOM shareware episode, (c) id Software. The original shareware game files
are redistributed unmodified. The shareware license and vendor information
from the original distribution are in shareware-license/.

The bundle starts the shareware episode directly at E1M1 with the command:
  DOOM.EXE -warp 1 1 -skill 3

Controls (DEFAULT.CFG):
  W/S = forward/back
  A/D = strafe left/right
  Q/E = turn left/right (optional keyboard fallback)
  Mouse = look/turn (captured by the player)
  Ctrl = fire, Space = use, Shift = run
  Esc = release mouse (press again or click X to exit)

Emulator
--------
js-dos 8.5.4 (GPL-2.0) — https://js-dos.com
The emulator files are vendored in jsdos/.
